# Version 1.0.0

**Release Date:** August 2026

Release Type: **Stable**

# Overview

Version 1.0.0 marks the first stable release of JobHunter AI.

This release introduces the core Career Intelligence Platform, providing resume analysis, ATS optimization, intelligent job discovery, company research, and professional PDF reporting.
