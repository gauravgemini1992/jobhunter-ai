# Contributing to JobHunter AI

Thank you for your interest in contributing to JobHunter AI.

## Reporting Issues

If you discover a bug or have a feature request, please create a GitHub Issue with:

- Clear description
- Steps to reproduce
- Expected behavior
- Screenshots (if applicable)

## Development Workflow

1. Fork the repository
2. Create a feature branch
3. Commit your changes
4. Push your branch
5. Open a Pull Request

## Coding Guidelines

- Follow PEP 8
- Keep functions modular
- Write meaningful commit messages
- Add tests where applicable

Thank you for helping improve JobHunter AI!
