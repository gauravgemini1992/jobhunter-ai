# 🚀 JobHunter AI

> ### AI-Powered Career Intelligence Platform

**Analyze • Optimize • Discover • Get Hired**

---

## 📖 Overview

JobHunter AI is an AI-powered Career Intelligence Platform built to help job seekers throughout their entire career journey.

Instead of using multiple websites and tools, JobHunter AI brings everything together into one intelligent platform.

It enables users to:

- Analyze resumes
- Improve ATS scores
- Discover relevant jobs
- Research companies
- Prepare for interviews (Upcoming)
- Build AI-powered resumes (Upcoming)

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/JobHunter-AI.git
```

Move into the project

```bash
cd JobHunter-AI
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python3 main.py
```
